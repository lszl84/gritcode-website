Keep an independent coding agent alive.

Gritcode is free, open source, and built by one developer, Luke, with help from AI agents. There's no VC money, no paid tier and no ads. If Gritcode saves you time or money, sponsoring is the best way to keep it growing.

What your support pays for

  • Signed macOS builds. An Apple Developer membership, so the app opens without security warnings.
  • API credits. Every release is tested against real DeepSeek models on real projects.
  • Time. Features like the editor, session replay and the new Tahoe look took weeks of evenings. Sponsorships turn evenings into focused work.
  • Independence. Gritcode stays free, open source and without a subscription.

Other ways to help

  • Star the repository on GitHub, which helps other developers find it
  • Write about Gritcode or share it with a friend who's tired of heavy apps
  • Report bugs and suggest features
  • Subscribe to DevMindscape on YouTube
  • Send a pull request. The code is C++20 and wxWidgets, and it's approachable.

Thank you
