Features

Streaming markdown

Headings, code blocks, bold, italic, inline code — rendered live as the model responds.

Efficient rendering

Blocks finalize at boundaries. No per-token repaint. Just a subtle thinking-dots animation while generating.

Select & copy anything

Character-precise selection across blocks. Copy code snippets or whole conversations.

System theme aware

Tracks your dark/light preference automatically. No config needed.

No API key needed

Default model works anonymously. Bring your own DeepSeek key when you want more.

Battery friendly

Update-region painting — only the newly exposed area repaints on scroll. Minimal GPU work.

Get started

No permission system. AI agents can execute commands on your machine. Press Escape to cancel a running request at any time.

Early days. This is a live project under active development. Things change fast and bugs happen. If you hit one, open an issue — ideally with an AI agent's analysis attached.

Arch / Manjaro

sudo pacman -S --needed base-devel cmake ninja git curl gtk3 pkgconf wxwidgets-gtk3

git clone https://github.com/lszl84/gritcode.git
cd gritcode
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
cmake --install build --prefix ~/.local
